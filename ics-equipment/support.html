ICS Equipment — Support

For Industrial Contract Services (ICS) employees

Getting help

Contact Randy Kraft at ICS: randy.kraft@icsgf.us.

Common questions

  • "Can't reach the equipment server" — the app works only on the ICS office or yard Wi-Fi. Join that Wi-Fi and try again. If you are on it, check Settings → Privacy & Security → Local Network → ICS Equipment is on.
  • Which login? — the same username (or email) and password as the ICS dashboard.
  • Scanning tags — tap the scan button next to the search box and allow camera access when asked (Settings → ICS Equipment → Camera). A hand-held scanner works too: it types the tag into the search box.
  • Some buttons are missing — moving, editing, photos and service records are for the tool crib. Project managers can look things up, request equipment, add rentals and comment.
  • The server moved — Settings → Server address → Test connection → Save.
